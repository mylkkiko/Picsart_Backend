1. При попытке использовать функции модуля будет ошибка, поскольку exports ссылается на module.exports, который ссылается на определенный объект. Node js просматривает данные только module.exports. Самой ошибки при подключении не будет, но вот при попытке использования функций из этого модуля да, поскольку в module.exports нету данных про модуль math.

2. В случае module.exports = ... экспортируется только одна функция, в случае exports.xxx = ... несколько функций, которые по очереди экспортируюся. Переписать math.js используя module.exports можно, изменив только один момент. module.exports = {}. В данном случае необходимо прописать экспортируемые функции. Со стороны импортирвоания никаких изменений не будет.

3. В случае commonJS у Node JS свой встроенный поиск по файлам, и если по названию файл не получается найти, поиск идет по расширениям .js, .json, .node. ESM по большей части нацелен на работу с браузером, и дабы поиск не был слишком долгим, нужно прописать четкий путь к файлу с расширением.
